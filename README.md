# Savoy Drugstore — Public Brand Kit Assets

This repository provides the minimal approved public identity assets required for read-only brand-system integrations. The authoritative project-local Brand Kit remains within the Savoy Drugstore project.

Only approved transparent PNG logo files and an asset manifest are published here. No customer information, credentials, account tokens, campaign data, internal marketing plans, or unapproved creative assets are stored in this repository.

Use immutable raw GitHub URLs from `Brand_Kit/Assets/asset_manifest.json` rather than mutable branch URLs.
